# Wallpaper Collection
This repository contains a curated list of high-quality wallpapers and their source URLs.

See the full collection in [Wallpaper.md](Wallpaper.md), which lists each wallpaper title and its source link.

How to use
- Open [Wallpaper.md](Wallpaper.md) to browse available wallpapers.
- Follow each source URL to download the original image and to verify licensing.
- To contribute, add a new line in [Wallpaper.md](Wallpaper.md) using the same format: `[n] "Title" (URL)`

Notes
- Verify image licenses on the original sites before using images for commercial projects.
- Keep entries concise and include a direct image URL when possible.
